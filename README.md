# Celnova Híbrido

**Descripción General Celnova**
Una aplicación de comercio electrónico híbrida desarrollada con Ionic, Angular y Capacitor, diseñada para ofrecer una experiencia de compra moderna, responsiva y multiplataforma en Web, Android e iOS.

**Tecnologías Principales**
Ionic, Angular, Capacitor

---

## Descripción

Celnova es una aplicación de comercio electrónico enfocada en la venta de productos tecnológicos y electrónicos. La aplicación permite a los usuarios navegar por categorías, buscar productos, gestionar un carrito de compras, gestionar favoritos, pagar y visualizar sus pedidos. Además, la aplicación ha sido desarrollada bajo una arquitectura híbrida que permite ejecutar una única base de código en navegadores web, Android y dispositivos iOS.

---

## Funcionalidades Principales

### Experiencia de Compra
- Catálogo de productos tecnológicos.
- Búsqueda por categorías.
- Visualización de productos.
- Detalles de productos.
- Productos destacados y ofertas.
- Lista de favoritos (Wishlist).
- Comparación de productos.
- Historial de productos.

### Carrito y Flujo Comercial
- Carrito de compras dinámico.
- Persistencia del carrito.
- Cálculo de subtotales.
- Gestión de pedidos.
- Checkout de compras.
- Simulación de envío personalizada.

### Gestión de Usuario
- Registro e inicio de sesión.
- Recuperación de contraseña.
- Perfil de usuario.
- Edición de perfil.
- Gestión de direcciones.
- Gestión y administración de preferencias.

### Checkout y Métodos de Pago
- Checkout estructurado en tres etapas:
  - Datos de entrega.
  - Revisión de pago.
  - Confirmación de compra.
- Métodos de pago disponibles:
  - Tarjetas bancarias.
  - Transferencias.
  - Carteras digitales.
  - Pago contra entrega.

### Funcionalidades complementarias:
- Gestión de cupones.
- Sistema de favoritos.
- Gestión de datos bancarios.
- Notificaciones promocionales.
- Notificaciones automáticas de envío.
- Seguimiento de órdenes.

## Funcionalidades Nativas

La aplicación incorpora capacidades mediante Capacitor:
- Acceso a la cámara para fotografías.
- Integración con dispositivos móviles.
- Generación y lectura de códigos QR.
- Escaneo y comparación de QR.
- Compatibilidad con NFC.
- Soporte para Android.
- Soporte para iOS.

## Instalación

## Compilación

Compilar el proyecto para generar los archivos de distribución:
ionic build

---

## Android

Ejecutar en Android:
ionic cap run android

## iOS
